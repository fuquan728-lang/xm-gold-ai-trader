# v0.5.3 Risk-Normalized Hypothesis Ranking

This checkpoint extends the read-only offline strategy hypothesis lab with
risk-normalized ranking across the existing hypothesis set.

## Scope

- Extended `scripts/strategy_hypothesis_lab.py --json`.
- Added top-level `risk_normalized_hypothesis_ranking`.
- Rankings compare the existing offline hypotheses under shared fixed-dollar
  risk budgets: `$2.50`, `$5.00`, `$10.00`, `$15.00`, and `$25.00`.
- Added pytest coverage for ranking output, deterministic rankings, candidate
  spam controls, and clean safety fields.

The ranking uses only historical/cached candidates and stored symbol metadata.
It does not connect to MT5, does not call `order_check`, and does not call
`order_send`.

## Ranking Inputs

Each hypothesis/budget row reports:

- total candidates
- feasible candidate count
- infeasible candidate count
- feasible percentage
- candidate and feasible BUY/SELL distribution
- median computed lot
- median normalized lot
- median stop distance and ATR points
- median risk shortfall
- top blockers

## Scoring Model

The score is intentionally risk-normalized and does not reward raw signal spam.
It balances:

- feasibility percentage
- capped feasible candidate count
- BUY/SELL balance
- lower median risk shortfall
- reasonable stop-distance profile
- small risk-gated bonus
- candidate-spam penalty versus the current baseline candidate count

The ranking is explicitly labeled `hypothetical_only: true` and
`not_production_selection: true`.
