# v0.3.6 Research Pipeline Readonly

Release checkpoint for `xm-gold-ai-trader`, focused on read-only research,
dry-run observation, historical diagnostics, and AI annotation auditing.

This checkpoint does not add AI model trading, does not call `order_check`, does
not call `order_send`, and does not enable order sending in the default
configuration.

## Completed Research Phases

- Phase 3.1 baseline backtest: reproducible SMA/ATR baseline backtest with
  spread cost, one position at a time, drawdown metrics, and no martingale/grid
  behavior.
- Phase 3.2 walk-forward robustness: sequential validation, spread/slippage
  stress matrix, parameter sensitivity, and pass/fail robustness gates.
- Phase 3.3 parameter stability: grid diagnostics, neighborhood stability,
  profitable-parameter coverage, and overfit warning flags.
- Phase 3.4 live dry-run journal: live `GOLD_` observation journal that never
  calls `order_check` or `order_send`.
- Phase 3.4.1 campaign tooling: bounded dry-run observation campaigns with
  campaign metadata and session summaries.
- Phase 3.4.2 bar-close dedup: optional bar-close-only observation mode with
  duplicate-bar skip accounting.
- Phase 3.4.3 observation quality gate: read-only quality evaluation over live
  dry-run journals and campaigns.
- Phase 3.4.4 historical signal replay: closed-bar historical replay using the
  same baseline signal logic as live dry-run observation.
- Phase 3.4.5 live vs historical expectation: comparison of live signal rate
  against historical replay expectation.
- Phase 3.5 AI annotation only: deterministic commentary-only annotations over
  dry-run signal journals.
- Phase 3.5.1 AI annotation audit: hash/source integrity, schema drift,
  duplicate annotation, and forbidden-trading-content checks.
- Phase 3.6 AI annotation vs signal analysis: joins annotations to dry-run
  signals by source hash and summarizes signal/regime relationships.
- Phase 3.6.1 research pipeline verification: end-to-end read-only verifier for
  tests, dry-run quality, historical expectation, annotation, audit, report, and
  signal-vs-annotation analysis.

## Current Status

- `python scripts\research_pipeline_verify.py --json` returns `WARN` only
  because live sample coverage is still low.
- No safety violations were reported by the research verifier.
- `configs/xm_gold_ai_trader.demo.yaml` still has
  `execution.allow_order_send: false`.
- AI is read-only commentary only. AI annotations do not change source
  `final_decision`, do not produce order instructions, and are audited for
  forbidden trading fields and terms.
- Research scripts report `orders_sent: 0`, `order_check_called: false`, and
  `order_send_called: false`.

## Known Strategy Warnings

- `STRESS_TEST_FRAGILE` remains a strategy robustness warning from parameter
  stability and stress diagnostics.
- Live dry-run sample coverage is still insufficient for strong conclusions.
- The actionable live signal rate is currently low, but remains consistent with
  historical expectation so far because the live sample is small.

## Safety Guarantees

- No AI trading.
- No `order_check` in Phase 3 read-only research scripts.
- No `order_send` in Phase 3 read-only research scripts.
- No martingale.
- No grid.
- No automatic lot increase after loss.
- AI annotations are commentary-only and are rejected if they contain forbidden
  trading fields or free-text trading instructions.
- Research pipeline verification blocks on any positive order count, order-check
  call, order-send call, or forbidden AI trading content.
