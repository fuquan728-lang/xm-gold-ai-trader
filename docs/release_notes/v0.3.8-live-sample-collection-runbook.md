# v0.3.8 Live Sample Collection Runbook

Release checkpoint for `xm-gold-ai-trader`, focused on operationalizing the
v0.3.7 live sample coverage reporting with a read-only collection runbook and a
read-only sampling progress command.

This checkpoint does not change trading logic, does not change strategy logic,
does not add AI model trading, does not call `order_check`, does not call
`order_send`, and does not enable order sending in the default configuration.

## Scope

- Added `scripts/check_live_sample_coverage.py` for read-only sampling progress.
- Added `docs/runbooks/live_sample_collection_runbook.md`.
- Documented how to use bounded
  `scripts\run_dry_observation_campaign.py --bar-close-only` runs to collect
  enough dry-run signal journals.
- Preserved v0.3.7 WARN behavior. The verifier still reports
  `UNIQUE_CLOSED_BARS_BELOW_MINIMUM` and `INSUFFICIENT_LIVE_SAMPLE` while live
  sample coverage is insufficient.

## Progress Check

Run:

```powershell
python scripts\check_live_sample_coverage.py --json
```

It reports:

- `current_unique_closed_bars`
- `required_min_unique_closed_bars`
- `remaining_closed_bars`
- `source_path`
- `source_glob`
- `latest_journal_time_utc`
- `latest_closed_bar_time`

The data source is `logs\dry_run_signals\*.json`, deduplicated by symbol,
timeframe, campaign id, and latest closed bar time.

## Collection Command

Run bounded bar-close-only campaigns over time:

```powershell
python scripts\run_dry_observation_campaign.py --symbol GOLD_ --timeframe M15 --interval-seconds 60 --max-iterations 10 --bar-close-only --json
```

The target remains:

```text
unique_closed_bars >= 100
remaining_closed_bars == 0
```

## Safety Status

- Default `configs/xm_gold_ai_trader.demo.yaml` remains
  `execution.allow_order_send: false`.
- `check_live_sample_coverage.py` reads local dry-run journals only.
- The collection command remains observation-only and must report
  `orders_sent: 0`.
- AI annotation and analysis remain read-only commentary.
- Any order activity, `order_check`, `order_send`, or forbidden AI trading
  content remains a BLOCK condition in the research pipeline verifier.
