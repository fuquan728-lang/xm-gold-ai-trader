# v0.4.0 Research Quality Analysis

Release checkpoint for `xm-gold-ai-trader`, created from the
`v0.3.9-live-sample-coverage-pass` baseline.

This checkpoint adds read-only analysis of the collected live dry-run samples.
It does not change trading logic, strategy thresholds, safety checks, order
routing, or AI annotation behavior.

## Scope

- Added `scripts/analyze_live_sample_quality.py`.
- The script reads `logs/dry_run_signals/*.json` and
  `logs/dry_run_campaigns/*.json`.
- Metrics default to unique closed-bar observations.
- The report includes:
  - total valid journals
  - unique closed bars
  - final `SIGNAL` count
  - candidate baseline signal count
  - block count and block rate
  - top block and no-action reasons
  - campaign distribution
  - closed-bar time distribution
  - historical replay expectation comparison when available
