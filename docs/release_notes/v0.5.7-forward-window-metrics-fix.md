# v0.5.7 Forward Window Metrics Fix

This checkpoint corrects the diagnostics coverage denominator to count only
enriched journals within the forward evidence window. Legacy pre-enrichment
journals that lack a `diagnostics` object are excluded from coverage
calculation.

## Scope

- Added `_collect_forward_window_stats()` helper that reads only enriched
  journals (schema_version >= 1) from `logs/dry_run_signals/*.json`.
- Updated `forward_sample_collection_plan()` to accept real window stats:
  enriched journal count, legacy exclusion count, closed bar count, final
  SIGNAL count, diagnostics coverage percentage, and top block reasons.
- Updated `run_strategy_hypothesis_lab()` to accept optional `journal_glob`
  parameter for testability.
- Updated pytest to pass an isolated journal glob.

## Problem

Before this fix, `forward_sample_collection_plan` used hardcoded zeros or a
global denominator that included 109 legacy pre-enrichment journals. This meant
coverage would never reach 95% regardless of how many enriched journals were
collected, because the legacy journals diluted the denominator.

## Fix

- **Denominator**: enriched journals only (those with `diagnostics` present).
- **Diagnostics coverage**: enriched journals with complete required diagnostic
  fields / total enriched journals.
- **Closed bars**: unique `latest_closed_bar_time` values from enriched journals.
- **Final SIGNAL count**: enriched journals where `action` is `BUY` or `SELL`.
- **Top block reasons**: aggregated from enriched journal diagnostic fields.
