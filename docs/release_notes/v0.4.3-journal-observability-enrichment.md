# v0.4.3 Journal Observability Enrichment

Release checkpoint for `xm-gold-ai-trader`, enriching live dry-run signal
journals with read-only observability fields for future research.

This checkpoint does not change trading logic, strategy thresholds, safety
checks, order routing, or AI annotation behavior.

## Scope

- Extended `scripts/live_dry_run_signal_journal.py` to add a backward-compatible
  `diagnostics` object to new live dry-run journals.
- The existing journal fields and `journal_schema_version` remain compatible
  with older readers.
- Extended `scripts/analyze_live_sample_quality.py` to prefer recorded
  diagnostics when present and gracefully fall back for older journals.
- Added tests proving:
  - old journals without diagnostics still parse
  - new journals include the diagnostics fields
  - missing legacy fields are marked as `not_recorded_in_journal`

## New Journal Diagnostics

New live dry-run journals now record:

- `fast_sma`
- `slow_sma`
- `previous_fast_sma`
- `previous_slow_sma`
- SMA crossover state
- ATR value
- stop distance
- computed lot
- normalized lot
- broker `volume_min`
- broker `volume_step`
- spread points
- max allowed spread points
- failed pre-signal rule names
- failed feasibility rule names

## Backward Compatibility

Older journals do not contain raw fast/slow SMA fields. The analysis report
continues to parse them and reports those values as `not_recorded_in_journal`.
Where possible, ATR is still reconstructed from recorded signal stop distance.

## Safety Status

- Default `configs/xm_gold_ai_trader.demo.yaml` remains
  `execution.allow_order_send: false`.
- `orders_sent` remains `0`.
- `order_check_called` remains `false`.
- `order_send_called` remains `false`.
- No Phase 3 research or AI script calls `order_check` or `order_send`.
- AI annotation remains read-only commentary.
- No martingale, no grid, and no lot increase after loss.
