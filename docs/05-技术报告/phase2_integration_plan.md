## 2. 实施任务分解

### 2.1 任务1：Socket服务器集成
**目标**: 将独立的Socket服务器组件完整集成到现有AI服务主流程架构中

**实施步骤**:
1. 分析现有AI服务主流程（`ai_file_server_optimized.py`）
2. 创建集成版本（`ai_service_integrated.py`）
3. 设计双模式运行架构：
   - 文件模式：保持现有文件轮询逻辑
   - Socket模式：启动TCP服务器处理实时请求
4. 实现模式切换控制逻辑
5. 确保AI核心逻辑的完全复用

**技术方案**:
- 使用`socketserver.ThreadingTCPServer`处理并发连接
- 每个连接独立线程，调用现有`AITradingService`
- 保持相同的JSON请求/响应格式
- 集成现有性能统计和日志系统

**交付物**:
- `ai_service_integrated.py` - 集成主程序
- `socket_handler.py` - 独立的Socket处理器模块
- 更新后的启动脚本

### 2.2 任务2：MQL5文件改造
**目标**: 对AI_Trader_Integrated.mq5进行全面修改，彻底替换文件通信为Socket通信

**实施步骤**:
1. 分析现有文件通信代码（`WriteRequestFile`/`ReadResponseFile`）
2. 创建Socket通信函数集：
   - `SocketRequest()`: 发送请求并接收响应
   - `SocketConnect()`: 建立连接
   - `SocketDisconnect()`: 关闭连接
3. 替换OnTick()中的文件通信逻辑
4. 添加通信模式切换支持
5. 实现错误处理和重试机制

**技术方案**:
- 使用MQL5内置Socket函数（`SocketCreate`, `SocketConnect`, `SocketSend`, `SocketReceive`）
- JSON over TCP协议，换行符分隔消息
- 连接超时和接收超时控制
- 指数退避重试策略

**交付物**:
- `AI_Trader_Integrated_Socket.mq5` - 支持Socket的EA版本
- `socket_utils.mqh` - Socket通信工具库（可选）
- 更新后的EA配置文件

**实施步骤**:

4. **监控日志**:
   - 详细错误日志（时间、类型、上下文）
   - 性能统计（成功率、响应时间、重试次数）
   - 健康状态报告

**技术方案**:
- 异常层级结构设计
- 重试装饰器模式
- 状态机管理连接状态
- 结构化日志记录

## 4. 技术架构设计

### 4.1 系统架构图
```
MT5 EA (客户端)                  Python AI服务 (服务器)
      │                                   │
      ├── 文件模式 ───────────────────────┤
      │   • WriteRequestFile()           │   • 文件轮询监控
      │   • ReadResponseFile()           │   • 文件读写处理
      │                                   │
      └── Socket模式 ─────────────────────┘
          • SocketRequest()               • TCP服务器监听
          • JSON over TCP                 • 多线程请求处理
          • 实时通信                      • 调用AI分析服务
```

### 4.2 数据流设计
1. **请求流程**:
   ```
   MT5 EA → 模式选择 → Socket/文件 → 请求发送 → Python接收 → AI分析 → 响应返回 → MT5处理
   ```

2. **错误处理流程**:
   ```
   发生错误 → 错误分类 → 重试判断 → 重试执行 → 成功/失败 → 降级切换 → 状态报告
   ```

3. **模式切换流程**:
   ```
   配置检查 → 模式验证 → 初始化对应模块 → 运行状态监控 → 动态切换（可选）
   ```

### 4.3 接口设计
1. **Python服务接口**:
   ```python
   class AIServiceIntegrated:
       def __init__(self, mode="auto"):
           self.mode = mode  # "socket", "file", "auto"
           self.socket_server = None
           self.file_monitor = None
           
       def start(self):
           """启动服务"""
           if self.mode == "socket" or (self.mode == "auto" and self._can_use_socket()):
               self._start_socket_server()
           else:
               self._start_file_monitor()
               
       def stop(self):
           """停止服务"""
           # 清理资源
   ```

2. **MQL5客户端接口**:
   ```mql5
   // 通信模式枚举
   enum CommunicationMode {
      MODE_AUTO,     // 自动选择
      MODE_SOCKET,   // Socket模式
      MODE_FILE      // 文件模式
   };
   
   // Socket请求函数
   bool SocketRequest(string request_json, string &response_json, int timeout_ms = 5000);
   ```
